Please QDVC Countdowns, an Android app that reads a CSV file with the following columns:

The CSV file may have other columns, but these 3 are the important ones. They represent events that the user is counting the days towards.

The user can:

1. Look at the list of countdowns.
2. Tap on a particular countdown to look at it in detail in a 'big' view (very visible days-until counter, maybe a good graphical icon to represent whether it's an event or an internal deadline or an external deadline)

- Daily digest: daily reminder to visit the app because 'there are (X) happening in the next week' (if X == 0, then 'there are (Y) happening in the next fortnight'; if Y==0, then 'there are (Z) happening in the next month'; if Z==0, then remind the user to visit in case the latest countdowns aren't registered).
    - Should be able to configure multiple reminders per day. Recommended 9AM and 3PM. Or can switch off entirely.

- Specific reminders: about specific events happening soon. Should be able to specify:
    - Multiple reminders for a given event. Recommended 10 days remaining, 7 days remaining, 3 days remaining, 2 days remaining, 1 day remaining, and event happening today.
